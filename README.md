## ✨ Why This Project Matters
Seaweed is a sustainable resource with applications in food, cosmetics, and pharmaceuticals.  
**Sri Lanka has ideal coastal conditions**, yet farming remains traditional and inefficient.  
Our system introduces **digital transformation** through:
- 🌱 **AI-powered species identification** for local varieties (_Kappaphycus alvarezii_, _Gracilaria edulis_)
- 🌡️ **IoT-based environmental monitoring** for indoor/outdoor farming decisions
- 📊 **Predictive harvest modelling** for better yield and income
- 📦 **Traceable packaging & AI-driven medicinal recommendations**

---

## 🔑 Key Modules

### 1️⃣ **AI Seaweed Identification**
- **🔍 Classifies _Kappaphycus alvarezii_, _Gracilaria edulis_, and rejects non-seaweed**
- Linked to a **knowledge base** with traits, uses, and nutritional info
- **Tech:** TensorFlow, PyTorch, OpenCV, React.js, Node.js, MongoDB  
<sup>🌟 First localized AI model for Sri Lankan species 🌟</sup>

---

### 2️⃣ **Environmental Suitability & Micro-Site Recommendation**
- **🌡️ Monitors temperature, pH, salinity, & light via IoT sensors**
- Recommends indoor/outdoor farming and ranks micro-sites
- **Tech:** ESP32, Node.js, React.js, MongoDB, Chart.js, D3.js  
<sup>🚀 Pioneering micro-site ranking in Sri Lanka 🚀</sup>

---

### 3️⃣ **Growth Monitoring & Harvest Prediction**
- **📱 Real-time weight-based growth tracking**
- Predicts harvest readiness using **Logistic Growth Model**
- **Tech:** ESP32, HX711, Python (Flask), React.js, MongoDB  
<sup>📊 First mobile harvest prediction for local seaweed 📊</sup>

---

### 4️⃣ **Packaging & Delivery with AI Prescription Calculator**
- **🔗 QR-enabled traceability, smart packaging, & AI product recommendations**
- Suggests food and medicinal uses with accurate ingredient ratios
- **Tech:** Node.js, React.js, MongoDB, TensorFlow, PyTorch  
<sup>🛡️ First all-in-one traceable post-harvest tool 🛡️</sup>

## 🚀 Getting Started

### **Clone the Repository**
```sh
git clone https://github.com/yourusername/Smart-System-for-Seaweed-Cultivation-and-Harvest-Management.git


# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install


# Start backend
npm start

# Start frontend
npm start
``

Access the app at: http://localhost:3000
