## 🎯 Overview

An integrated digital platform that transforms traditional seaweed farming through automated species identification, real-time environmental monitoring, predictive harvest analytics, and traceable post-harvest management—designed specifically for Sri Lanka's coastal communities.

## 💡 The Challenge & Our Solution

**The Problem:**  
Sri Lanka's coastline offers ideal conditions for seaweed cultivation, yet farmers rely on traditional methods that limit efficiency, yield predictability, and market value.

**Our Innovation:**  
A comprehensive digital transformation platform that integrates:
- AI-powered species identification for *Kappaphycus alvarezii* and *Gracilaria edulis*
- Real-time IoT environmental monitoring and micro-site recommendations
- Predictive harvest modeling using growth analytics
- Blockchain-inspired traceability through QR-coded packaging

---

## 🔬 Core Modules

### Module 1: AI-Powered Species Identification
**Breakthrough:** First localized AI model for Sri Lankan seaweed species

- Automated identification with non-seaweed rejection
- Integrated knowledge base for traits, uses, and nutrition
- **Stack:** TensorFlow, PyTorch, OpenCV, React.js, Node.js, MongoDB

### Module 2: Environmental Intelligence & Site Optimization
**Innovation:** Pioneering micro-site ranking system for Sri Lanka

- Real-time monitoring of temperature, pH, salinity, and light intensity
- Indoor/outdoor cultivation recommendations
- Comparative site performance analytics
- **Stack:** ESP32, Node.js, React.js, MongoDB, Chart.js, D3.js

### Module 3: Growth Analytics & Harvest Prediction
**First-of-its-kind:** Weight-based harvest prediction for local species

- Continuous growth tracking via IoT sensors
- Logistic Growth Model for optimal harvest timing
- Yield forecasting and income projection
- **Stack:** ESP32, HX711 Load Cell, Python (Flask), React.js, MongoDB

### Module 4: Smart Packaging & Value Addition
**Complete solution:** End-to-end post-harvest management

- QR-based product traceability
- AI-driven food and medicinal recommendations
- Precise ingredient ratio calculations
- **Stack:** Node.js, React.js, MongoDB, TensorFlow, PyTorch

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ and npm
- Python 3.8+
- MongoDB 4.4+
- Arduino IDE (for ESP32 setup)

### Installation

```bash
# Clone the repository
git clone https://github.com/ishendulara/Smart-System-for-Seaweed-Cultivation-and-Harvest-Management.git
cd Smart-System-for-Seaweed-Cultivation-and-Harvest-Management

# Install backend dependencies
cd backend
npm install

# Install frontend dependencies
cd ../frontend
npm install

# Configure environment variables
cp .env.example .env
# Edit .env with your MongoDB connection and API keys

# Start the backend server
cd backend
npm start

# In a new terminal, start the frontend
cd frontend
npm start
```

Access the application at `http://localhost:3000`
